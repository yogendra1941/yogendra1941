# Upload guide

1. Extract `yogendra-animated-github-profile.zip`.
2. Open the public profile repository `yogendra1941/yogendra1941`.
3. Upload `README.md` and the complete `assets/` directory at the repository root.
4. Commit changes.
5. `preview.html`, `LICENSES.md`, and this guide are useful for preview/documentation but are not required for GitHub to display the profile.

Edit Skills and Featured Projects directly in README.md. SVG text and layout can be edited in `assets/*.svg`.
